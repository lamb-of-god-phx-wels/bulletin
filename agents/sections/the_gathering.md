## Introductions

There are a set of static introductions under /assets/service_intros. These 
are used as-is. They may contain multiple sub-sections.

## Format

- All sub-text uses:
    - Calibri
    - 11 pt
    - Left-justified
- Sub-sections are:
    - Bold
        - If there is a colon, text after the colon is not bolded, but
          italicized and is title case
        - If there is a sub-title put it on its own line and use italics and
          regular sentence case.
    - All-caps
    - Left-justified
